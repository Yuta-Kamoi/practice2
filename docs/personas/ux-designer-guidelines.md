# UX Designer — Guidelines

Purpose: Outline UX responsibilities and collaboration patterns.

## Responsibilities
- Create and maintain user flows, wireframes, and design specs
- Run quick usability validations for new features
- Provide acceptance criteria focused on usability
- Capture post-release UX feedback and recommend iterations

## Collaboration
- Join planning to surface UX risks and required research
- Review engineering implementation for design fidelity
- Work with QA to ensure usability scenarios are covered in tests
